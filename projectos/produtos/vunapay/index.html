Três superfícies de produto, uma rede de liquidação.

VunaPay liquida transferências entre bancos em menos de 3 segundos, conta-a-conta, sem carteira intermediária. Estes mocks demonstram a app do consumidor, o portal de operações dos bancos participantes, e a topologia da rede para revisão de stakeholders antes da implementação.

Como navegar este pacote

1. Sistema de Design

Comece pelo Sistema de Design. Define cor, tipografia, componentes e estados que todas as superfícies reutilizam. Tem alternador claro/escuro.

2. Superfícies clicáveis

Cada superfície tem todos os passos do fluxo numa só página, lado a lado. Útil para revisão; em produção cada passo é uma rota separada.

3. Documentos DESIGN-*.md

Cada superfície tem um documento autoritativo (ex.: DESIGN-send.md) descrevendo propósito, fluxos, componentes, estados e questões abertas. Para handoff a engenharia.
