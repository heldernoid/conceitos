# VunaPay · Conceitos

Rede de liquidação interbancária instantânea. Transferências conta-a-conta em menos de 3 segundos, sem carteira intermediária — app do consumidor, portal de operações dos bancos participantes e topologia da rede.

[→ Abrir protótipo](https://conceitos.org/projectos/produtos/vunapay/)

## Estrutura

```
vunapay/
├── index.html                   # Visão geral e navegação
├── home.html                    # Home da app do consumidor
├── onboarding.html              # Onboarding
├── send.html                    # Enviar
├── receive.html                 # Receber
├── transaction.html             # Detalhe de transacção
├── bank-portal-dashboard.html   # Portal Banco · Dashboard
├── bank-portal-participants.html # Portal Banco · Participantes
├── bank-portal-transactions.html # Portal Banco · Transacções
├── infrastructure.html          # Topologia da rede
├── design-system.html           # Sistema de Design
├── shared/styles.css
└── DESIGN-*.md                  # Documentação de design por superfície
```
